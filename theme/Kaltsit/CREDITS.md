## Permission record

The maintainer supplied a screenshot of a conversation with the original creator dated **2026-10-24**.
The request asked to adapt the Windows cursors for Linux and submit the adaptation to **nixpkgs**,
so other Linux users could install it. It expressly promised author attribution,
a link to the original work, and non-commercial use.

The creator replied:

> 可以的，如果方便请在评论区也发一下

The maintainer then agreed to share installation instructions and the project link
in the original work's comment section after submission, and the creator acknowledged it.

This permission is specific to the described adaptation and submission. It does not
assign copyright or place the artwork under a standard free-software license.
See [LICENSE](LICENSE) for the distinction between artwork and new tooling.
The private conversation screenshot is retained by the maintainer and is not included in this repository.

## Source preservation

The 17 original `.ani` files were supplied in `凯尔希+·+思衡托.zip` and are
preserved byte-for-byte under `assets/windows` for reproducible conversion.
`install.inf` is preserved as a record of Windows role mappings and is never executed.
The build report records each input's SHA-256 and every output frame's hotspot and timing.
